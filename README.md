# RSE360

CSR (RSE) platform for companies: diagnostic, action plans and reporting.

## Features

- Instant diagnostic
- Action plans
- Compliance and reporting

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/impact-compass.git
cd impact-compass
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
